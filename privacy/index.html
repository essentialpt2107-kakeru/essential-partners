1取得する情報

当社は、事業に必要な範囲で、適正な方法により、次のような情報を取得します。

  • お名前、ふりがな、生年月日、性別
  • 電話番号、メールアドレス、ご住所、LINE などのご連絡先
  • ご予約、ご来店、ご購入、お支払いの内容
  • カウンセリングの内容や、お肌・お体の状態など、施術やサービスを安全に行うために必要な情報
  • 施術の前後の写真（ご本人の同意をいただいた場合）
  • 結婚相談所などのサービスのお申し込みやご相談の際に、そのサービスの提供に必要な情報
  • アンケート、ご感想、お問い合わせの内容
  • 当社のツールをご利用の際に、連携したサービスから受け取る情報（8. 外部のサービスと連携するツールをご覧ください）

お体の状態など、特に配慮が必要な情報は、ご本人の同意を得たうえで取得し、施術の可否の判断と安全なご提供のためだけに使います。

2利用目的

取得した情報は、次の目的のために使います。

  1. ご予約の受付と管理、サービスや商品のご提供
  2. 施術やカウンセリングの内容を記録し、ご本人に合ったご提案をするため
  3. ご予約の確認や変更などのご連絡、アフターフォロー
  4. キャンペーンやお知らせのご案内（ご希望の方に限ります。いつでも停止を申し出ていただけます）
  5. アンケートの集計と、サービスの改善
  6. 施術の前後の写真を、効果の確認とご本人へのご提供に使うため（宣伝などに使う場合は、事前に掲載の許可をいただきます）
  7. お問い合わせへのお返事
  8. お取引先とのご連絡、契約にもとづく業務
  9. 法令にもとづく対応

3第三者への提供

当社は、次の場合を除き、ご本人の同意なく個人情報を第三者に提供しません。

  • 法令にもとづく場合
  • 人の生命、身体または財産を守るために必要で、ご本人の同意を得ることが難しい場合
  • 公衆衛生の向上や児童の健全な育成のために特に必要で、ご本人の同意を得ることが難しい場合
  • 国の機関や地方公共団体などが法令に定める事務を行うことに協力する必要があり、ご本人の同意を得ることでその事務に支障が出るおそれがある場合

4業務の委託と外部のサービス

予約の管理、お支払い、データの保管などのために、業務の一部を外部の事業者に任せたり、外部のサービス（クラウドサービスなど）を利用したりすることがあります。その場合は、必要な範囲でのみ情報を預け、預け先が適切に取り扱うよう管理します。外国にある事業者のサービスを利用する場合も、法令に従って取り扱います。

5安全管理

個人情報の漏えい、滅失、き損を防ぐため、次のような対策をとります。

  • 個人情報を取り扱う人と範囲を、必要なものに限ります
  • 情報を保存する機器やサービスを、パスワードなどで守ります
  • 使わなくなった情報は、適切な方法で消去します
  • 業務を外部に任せる場合は、預け先を適切に管理します

ご本人から、ご自身の個人情報について、利用目的のお知らせ、開示、訂正・追加・削除、利用の停止・消去、第三者への提供の停止のご請求があったときは、ご本人であることを確認したうえで、法令に従って速やかに対応します。9. お問い合わせ窓口までご連絡ください。

8外部のサービスと連携するツール（SPINDLE）

SPINDLE（スピンドル）は、当社が作った、Instagram・Threads などの SNS と Google ビジネスプロフィールの投稿を管理するツールです。当社や、SPINDLE を導入したお店のパソコンの中で動きます。

受け取る情報と使い方

  • Google ビジネスプロフィール（Google Business Profile API）：ご利用者が SPINDLE の「Google で連携」で許可したときだけ、ご利用者が管理しているビジネスアカウントとお店の情報（お店の名前・住所など）を読み込み、ご利用者が選んだお店に「最新情報」の投稿を作ります。お願いする許可は、ビジネスプロフィールの管理（business.manage）だけです。Google アカウントのパスワード、Gmail、連絡先など、ほかの Google のデータは読みません。
  • Instagram・Threads など：ご利用者が連携したアカウントの投稿、反応の数、コメントなどを読み込み、ご利用者が作った投稿を予定どおりに出します。
  • AI の機能：文章や画像の作成を手伝う AI の機能を使ったときは、その作業に必要な文章などを AI の提供会社（OpenAI、Google）に送ります。Google ビジネスプロフィールから受け取った情報は、AI に送りません。

保存する場所

受け取った情報は、SPINDLE が動いているパソコンの中だけに保存します。連携のための鍵（アクセストークンなど）は、パソコンの安全な保管場所（macOS のキーチェーン）に入れます。当社のサーバーに送ったり、当社が集めたりすることはありません。

連携の手続きの途中で、当社のホームページの中継ページ（essential-partners.co.jp/spindle/callback）を通ることがあります。このページは、受け取った情報を保存せず、そのままパソコンの SPINDLE に渡します。

Google から受け取った情報の取り扱い

SPINDLE が Google API から受け取った情報の利用と、ほかのアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含みます）に従います。

  • ご利用者が SPINDLE で行う操作（お店の選択と投稿）のためだけに使います
  • 販売しません。広告には使いません
  • AI のモデルの学習には使いません
  • ご利用者の同意がある場合、セキュリティのために必要な場合、法令に従う場合を除き、人が読むことはありません

連携の解除と情報の削除

  • SPINDLE の設定で「連携を外す」を押すと、パソコンに保存した Google との連携の鍵を消し、自動の投稿も止めます。
  • Google 側の許可は、Google アカウントの「サードパーティ製のアプリとサービス」のページ（https://myaccount.google.com/connections）から、いつでも取り消せます。
  • SPINDLE に保存された情報を消したいときは、9. お問い合わせ窓口までご連絡ください。消し方をご案内します。

SPINDLE and Google user data (English summary)

SPINDLE is a social media and Google Business Profile posting tool made by Essential Partners LLC. It runs only on the computer of the business that uses it.

  • Data accessed: Only after the user grants permission (scope: https://www.googleapis.com/auth/business.manage), SPINDLE reads the Business Profile accounts and locations the user manages (such as location names and addresses) and creates Local Posts ("Updates") on the location the user selects. It does not access the user's password, Gmail, contacts or any other Google data.
  • Storage: Data is stored only on the user's own computer, and OAuth tokens are kept in the macOS Keychain. Nothing is sent to or stored on our servers.
  • Use and sharing: Data is used only to provide the posting features the user operates in SPINDLE. We do not sell it, use it for advertising, use it to train AI models or send it to AI services. People do not read it except with the user's consent, for security purposes, or to comply with the law.
  • Limited Use: SPINDLE's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
  • Deletion: The user can disconnect in SPINDLE's settings, which deletes the stored token, and can revoke access at any time at https://myaccount.google.com/connections. To delete other stored data, please contact us (see section 9).
